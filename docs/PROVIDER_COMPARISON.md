# Telecom provider comparison — discovery only

No provider is selected and no telecom service is activated during Stage 1.

| Candidate | Verify before selection |
| --- | --- |
| Telnyx | WebRTC/Android integration, outbound PSTN, inbound numbers, SMS countries, pricing, KYC |
| Twilio | Voice SDK support, messaging sender restrictions, geographic coverage, number inventory, pricing |
| Vonage | Voice SDK, number coverage, inbound SMS, compliance, pricing |
| Plivo | Voice/SMS APIs, mobile client integration feasibility, regional coverage, pricing |

Selection criteria: lawful availability in target country, reliable voice/SMS, incoming calls, number ownership and renewal, webhooks, cost, support, security, and operational limits. Do not promise Yemen/Saudi numbers or verification SMS support without provider confirmation.
